## เป้าหมาย (จาก user)
1. **รับ LINE profile** (`lineUserId`/`displayName`/`pictureUrl`/`email`) — ปุ่มสแกน QR (payload=JSON) + tab กรอกเอง
2. **External API** ดึงประวัติ+stats+ลิงก์วิดีโอ query ด้วย lineUserId/email + ต้องมี **API auth key**
3. **Room login** — เปลี่ยน email login → `roomUser`/`roomPassword` (ห้อง 1,2,3,4), เปลี่ยนชื่อ field ใน DB, ลบของเก่าได้
4. player email เก็บเป็น `lineEmail`

## PO decisions
- LINE profile อยู่หน้า Home ก่อน session (per-player) · API key = single env `HISTORY_API_KEY` (x-api-key) · video = proxy URL ที่ต้องใช้ key · ประวัติ = เท่าที่มีจริง (3วัน + stats ถาวร) · cost ไม่โชว์ใน ext API
- room login = แทน email ทั้งระบบ · admin = roomUser พิเศษ (env ADMIN_USER/ADMIN_PASS)

## ⚠️ Identity model
- `roomUser` = บัญชีห้อง (แชร์, ไม่ใช่ตัวผู้เล่น) — เดิม ownerEmail
- `lineUserId` = key ต่อ session ของผู้เล่นแต่ละคน · `lineEmail` = email ส่วนตัว (lowercased)
- ไม่มี backfill: ext API เห็นเฉพาะ session หลังผูก profile
